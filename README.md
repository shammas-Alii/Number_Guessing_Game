#  Number Guessing Game

A clean and interactive command-line **Number Guessing Game** built in Python as part of the Syntecxhub Internship Program.

## Features
- Randomly generates a number for the user to guess.
- Provides helpful higher/lower hints.
- Counts attempts and tracks progress.

## How to Run
1. Make sure you have Python installed on your system.
2. Run the script using your terminal or VS Code:
   ```bash
   python 01_NumberGussing.py
